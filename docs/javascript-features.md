# JavaScript features used on the site

The site keeps its interactions simple and easy to understand.

1. Mobile menu toggle
   - Clicking the hamburger button opens and closes the navigation panel.
   - This helps the site stay clear and mobile-friendly.

2. Reveal-on-scroll animation
   - Section content fades into view as the user scrolls.
   - This is done with a small IntersectionObserver and a single CSS class.

3. Project filtering
   - The project cards can be filtered by category using the buttons above the grid.
   - This keeps the portfolio lightweight while still feeling interactive.
